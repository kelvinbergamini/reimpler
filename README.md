# Site REIMPLER

Projeto React + Vite pronto para publicação.

## Publicar sem instalar nada
1. Crie um repositório no GitHub.
2. Use **Add file > Upload files** e envie todo o conteúdo desta pasta, preservando as pastas.
3. Na Vercel, escolha **Add New > Project**, conecte o repositório e clique em **Deploy**.
4. A Vercel detectará Vite. Build command: `npm run build`. Output: `dist`.

## Formulário
O formulário envia para o Formspree pelo endpoint `xeageylw`. Confirme o e-mail de destino no painel do Formspree.

## Domínio
Depois do deploy, adicione `reimpler.com` e `www.reimpler.com` em Project Settings > Domains na Vercel e atualize o DNS no registrador do domínio.
